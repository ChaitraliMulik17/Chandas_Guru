# Chandas Guru

Explainable Sanskrit Prosody Analyzer and Learning Platform.

## Project Components

- Sanskrit text normalization
- Syllable segmentation
- Laghu/Guru detection
- Gana calculation
- Pada detection
- Chandas identification
- Explainable results
- Learning module
- Practice/quiz module
